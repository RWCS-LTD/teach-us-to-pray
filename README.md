# Teach Us to Pray

A free web app that teaches people to pray in their own words, following the pattern Jesus gave in the Lord's Prayer (Matthew 6:5-15, Luke 11:1-4).

It exists only to serve the ministry of Jesus. There is no profit, no ads, no tracking, no donations and no accounts.

## Rules that do not change

- **Free to run forever.** Static files only: no server, no database, no AI, no paid service.
- **Faithful to the text.** All teaching shown is Scripture, quoted exactly with its reference. Nothing is paraphrased. The only words of ours are the step names, the questions, the button labels and the About page.
- **Private.** What a person writes never leaves their device. No cookies, no analytics, no outside scripts, fonts or addresses.
- **The app never writes a prayer.** Every text box starts empty and is filled only by the person.
- **The order is fixed.** The seven steps follow Matthew 6:9-13: the Father, his name, his kingdom and will, and only then our own requests.
- **Public-domain Scripture only.** Never add ESV, NIV, NLT, NASB or other copyrighted text.

Changes to the verses or questions are theological changes and need the maintainer's approval.

## What is in here

| Path | What it is |
|---|---|
| `index.html`, `css/app.css`, `js/app.js` | The whole app |
| `lang/en.json` | Every piece of text a person sees, and which verses go with each step |
| `scripture/en-web.json` | The verse text, generated by a script from the World English Bible |
| `sw.js`, `manifest.webmanifest`, `icons/` | Offline use and "add to home screen" |
| `tools/` | Scripts for maintainers (Python 3, standard library only) |
| `review/content-review.md` | Every step with its verses written out, for review |

## Run it on your own computer

You need Python 3 (any simple web server will do).

```
python -m http.server 8000
```

Then open `http://localhost:8000`. Opening `index.html` directly from the folder does not work, because browsers block local file loading.

## Check it before releasing

```
python tools/verify.py
```

This confirms that the bundled verses match the World English Bible source exactly, that every reference resolves, that the offline file list is complete, that the app is under 100 KB, and that there is no outside address or cookie code.

## Scripture

The text is the World English Bible (WEB) from [eBible.org](https://ebible.org/), which is in the public domain. "World English Bible" is a trademark of eBible.org.

Verses are never typed by hand. To add or change a passage:

1. Add it to `PASSAGES` in `tools/build_scripture.py`.
2. Run `python tools/build_scripture.py`.
3. Refer to it in `lang/en.json` by its code, for example `"JHN 15:7"`. Verses that belong together go in one group: `["MAT 18:21", "MAT 18:22"]`.
4. Run `python tools/make_review.py` and read `review/content-review.md`.

Matthew 6:13 is shown as 6:13a, ending at "deliver us from the evil one". The World English Bible prints one more sentence, with a footnote that some Greek texts omit it. The build stops if that sentence ever appears in the output.

Each step has a pool of related passages. Two are shown each day, chosen from the date alone, and the rest sit under "More from Scripture for this step".

## Adding a language

1. Find a **public-domain** Bible translation in that language. eBible.org lists many and states the licence of each. Do not use a copyrighted translation.
2. Copy `tools/build_scripture.py` settings for that translation: its download address, file naming, and the split markers for Matthew 6:9 and 6:13. Write the output to `scripture/<language>-<translation>.json`, for example `scripture/es-rv1909.json`.
3. Copy `lang/en.json` to `lang/<language>.json`, for example `lang/es.json`. Translate every value. Keep the verse codes unchanged. Set `meta.lang`, `meta.dir` (`ltr` or `rtl`), `meta.scriptureFile`, `books` and `app.translationCredit`.
4. Add the language code to `LANGS` at the top of `js/app.js`. The app picks the first of the person's browser languages that is in this list, and falls back to English.
5. Add both new files to `FILES` in `sw.js` and change `CACHE` to a new name.
6. Run `python tools/verify.py` and `python tools/make_review.py <language>`, and have a fluent reader review the result.

The home-screen name in `manifest.webmanifest` and the short no-JavaScript message in `index.html` are in English only.

## Deploying

The app is plain files, so any static host works. For GitHub Pages:

1. Push this folder to a public GitHub repository.
2. In the repository, open Settings, then Pages, and choose "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<username>.github.io/<repository>/` over HTTPS.

**After any change to a shipped file, change `CACHE` in `sw.js`** (for example `-v1` to `-v2`). Otherwise people who already installed the app keep the old files.

## Privacy notes for maintainers

- A Content-Security-Policy in `index.html` allows the page to load files from its own address only.
- Text is kept in memory. It is written to the browser's `localStorage` only if the person switches on "Keep my draft on this device", and "Erase my words" removes it.
- Spell-check is switched off on the text boxes, because some browsers send text to an online service to check it.
